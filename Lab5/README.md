# Python Lab 5 — Python Dictionaries

## 📌 Overview

This lab focuses on Python dictionaries and their practical applications. It covers dictionary operations, nested dictionaries, comprehensions, data handling, output prediction, and conceptual questions.

The assignment is divided into three parts:

- **Part A:** Five practical Python programs.
- **Part B:** Predicting the output of Python dictionary programs.
- **Part C:** Short reasoning questions and answers about dictionaries.

## 🎯 Objectives

- Understand dictionary creation, access, modification, and deletion.
- Work with nested dictionaries and dictionary methods.
- Perform CRUD operations.
- Apply dictionary and list comprehensions.
- Perform searching, sorting, grouping, and aggregation.
- Understand dictionary copying and aliasing.
- Learn dictionary lookup and time complexity.
